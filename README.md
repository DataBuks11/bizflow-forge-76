# BizFlow Forge 76

## Project Overview
A business workflow automation platform built by **DataBuks Technology Services**.

## DataBuks AI Orchestration
Developed using the **DataBuks AI Orchestrator** engine, which bridges the gap between prompt and working production systems. Features include automated database schema generation and containerized environment setup.

## Technical Stack
- Vite
- TypeScript
- React
- shadcn-ui
- Tailwind CSS
- Google Maps API
- Supabase

## Getting Started
1. `npm install` to set up dependencies.
2. `npm run dev` to start the development environment.
